eSIM 怎么装？iOS 与 Android 完整步骤

核心原则：出发前在家的 WiFi 环境下装好，落地只需要切换一下数据线路。

落地才装是新手最常见的错误 —— 机场 WiFi 往往需要手机号收验证码， 而你的原卡可能已经切换，陷入死循环。

出发前：安装

iPhone

方式一：扫码（推荐）

  1. 打开「设置」→「蜂窝网络」
  2. 点击「添加 eSIM」
  3. 选择「使用二维码」，扫描品牌发来的二维码
  4. 按提示完成添加，给这个号码起个名字（如「日本 eSIM」）

方式二：手动输入

如果二维码扫不上，选择「手动输入详细信息」， 填入品牌提供的 SM-DP+ 地址和激活码。

方式三：App 内一键安装

多数品牌 App 支持在 App 内直接安装，最省事。 Airalo、Saily、Holafly 都支持。

Android

不同厂商路径不同，但逻辑一致：

  1. 打开「设置」→「网络和互联网」→「SIM 卡」
  2. 点击「添加 SIM」或「+」
  3. 选择「下载 SIM 卡」或「扫描二维码」
  4. 完成添加

部分国产 Android 系统的 eSIM 入口在「设置 → 连接 → SIM 卡管理器」。

⚠️ 注意：多数国行 Android 手机不支持 eSIM。装之前先确认机型。

出发前：设置

安装完成后，先别启用。回到「蜂窝网络」做两件事：

1. 关闭 eSIM 的「数据漫游」（落地后再开）

2. 把「默认语音线路」保持为你原来的卡

这样你仍然能收到国内短信验证码。

💡 部分系统会在添加 eSIM 后询问「用于什么用途」， 选择「仅蜂窝数据」即可。

落地后：启用

到达目的地后：

  1. 打开「设置」→「蜂窝网络」
  2. 把「蜂窝数据」切换到你的 eSIM
  3. 打开该 eSIM 的「数据漫游」
  4. 等待 30 秒到 2 分钟，信号栏出现运营商名称即成功

如果没网，先做这三步：

  • 打开飞行模式再关闭（重新注册网络）
  • 确认「数据漫游」已开（多数 eSIM 必须开漫游才能用）
  • 手动选择运营商（设置 → 运营商 → 关闭自动 → 手动选）

常见安装问题

Q：提示「无法添加 eSIM」？

可能是：① 手机型号不支持 ② 已有太多 eSIM（多数机型上限 8–10 张） ③ 二维码已过期（多数品牌有效期 30 天）

Q：装好了但显示「无服务」？

正常。未到达目的地前 eSIM 无法连接当地网络。 到目的地开启漫游后会自动连上。

Q：能同时保留原卡吗？

能。iPhone XS 之后支持双卡双待（一张实体 + 一张 eSIM，或两张 eSIM）。 原卡保留才能收国内验证码。

Q：装错了怎么删？

设置 → 蜂窝网络 → 选中该 eSIM → 「移除蜂窝套餐」。 注意：删除后通常无法恢复，需要重新购买。 别乱删。
